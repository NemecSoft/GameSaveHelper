# 2026-09-08

## GameSaveHelper：通用游戏存档备份助手（已交付）

按 `需求描述.md` 实现：命令行传入「路径+通配符」（1~8 个），自动生成 NSI 并编译出自解压备份包 exe。

### 产出文件
- `GameSaveHelper.bat` — 入口。故意用**纯 ASCII**（cmd 编码坑），只做参数透传 + `chcp 65001` + 调 PowerShell
- `tools/Build-GameSave.ps1` — 生成器（**必须 UTF-8 BOM**，否则 PS5.1 中文乱码）
- `template/GameSaveHelper.nsi` — NSI 模板，`@@占位符@@` 由生成器填充
- `examples/` — 两个示例 bat + 一份填充后的 NSI 样例
- `README.md`、输出目录 `out/`

### 关键技术点（踩过的坑，务必记住）
1. **`CopyFiles` 不能加 `/FILESONLY`** —— 加了就不递归子目录，导致 `2074800\remote\*` 全部丢失。去掉后正常递归。
2. **`/D=` 是 NSIS 内置参数**（会设置 `$INSTDIR`），不能用 `${GetOptions}` 解析，它会被 NSIS 消费掉。正确做法：模板里写 `InstallDir` 默认值，在 `.onInit` 里比较 `$INSTDIR != 默认值` 来判断用户是否传了 `/D=`，并额外判空。
3. **PowerShell 双引号字符串里 `${XXX}` 会被当变量展开**。要输出字面 `${BACKUP_STAMP}` 必须写 `` `${BACKUP_STAMP} ``（只转义 `$`，花括号原样）。曾因写成 `` `$`${BACKUP_STAMP} `` 导致时间戳变成 `0260908`（首位 `2` 被 NSIS 当成 `$2` 变量吃掉）。
4. **NSI 字符串转义**：`$`→`$$`、`"`→`$"`、反引号→`` $` ``（生成器里的 `ConvertTo-NsisString`）。
5. **nsDialogs 自定义页可用高度约 123u**。位置数 ≥3 时改双列；tip 复选框只在 `(tipY+10) <= 122` 时显示，否则隐藏（功能仍默认开启）。
6. bat 传中文参数给 `-File` 的 ps1 是安全的（cmd 内部 Unicode），不需要临时文件中转。
7. Git Bash 会做 MSYS 路径转换，**测试 exe 参数必须用 PowerShell 工具**，否则反斜杠变正斜杠。PowerShell 工具的 stdout 常被吞，结果要写文件再用 Bash 读。

### 生成的备份包能力
- GUI：欢迎页 → 自定义页（还原到原始位置 / 指定文件夹 + 位置多选 + 备份现有文件）→ 还原 → 完成页可打开文件夹
- 命令行：`/S` 静默还原原始位置；`/S /D=路径` 静默导出
- 覆盖保护：目标已存在则整个目录 `Rename` 为 `xxx.bak_时间戳`，不丢数据
- 默认递归子目录（`-norecurse` 关闭）；自动跳过 Steam 纯数字目录来推断游戏名
