# GameSaveHelper — 通用游戏存档备份助手

按指定的「路径 + 通配符」收集存档文件，自动填充 NSIS 模板并编译出一个**自解压备份包 exe**。
双击备份包，一步到位还原；生成的备份包默认放在**系统桌面**。

主程序：`GameSaveHelper.exe`（纯 Win32 C++，约 280 KB，静态链接，启动即用）

---

## 用法（严格检查，不做推断）

### 方式一：游戏名 + 路径参数

```bat
GameSaveHelper.exe 大富翁11 "D:\games\Z\Richman 11\2074800\*.*" "D:\games\Z\Richman 11\settings\*.*"
```

- 第一个参数：游戏名（不能是路径、不能是选项）
- 后面的参数：必须是用引号包裹的完整路径（支持通配符），1～6 个
- 产物：`桌面\大富翁11_年月日_时分秒.exe`（时间精确到秒）

### 方式二：只有游戏名（走 config.json）

```bat
GameSaveHelper.exe 大富翁11
```

程序会到 **当前目录** 或 **exe 所在目录** 找 `config.json`，按游戏名取存档路径：

```json
{
  "大富翁11": [
    "D:\\games\\Z\\Richman 11\\2074800\\*.*",
    "D:\\games\\Z\\Richman 11\\settings\\*.*"
  ]
}
```

（项目根目录有一份 `config.json` 示例，直接改。）

### 无参数

显示空白窗口。

## 备份包（生成出来的 exe）怎么用

| 操作 | 效果 |
|---|---|
| 双击 → 点「还原备份」 | 显示原路径（每行可修改/浏览），确认覆盖后还原到原位置 |
| 勾选/取消某个位置 | 只还原勾选的位置 |
| `备份包.exe /S` | 静默还原到原始位置 |
| `备份包.exe /D=D:\某文件夹` | 导出到指定文件夹（不覆盖原位置） |

覆盖保护：目标位置已有文件时，整个目录先被改名为 `xxx.bak_时间戳`，绝不直接覆盖。

---

## 异常报告

以下情况会明确报错并中止（错误写明是哪个位置、哪个文件）：

- 目录不存在
- 路径没有匹配到任何文件
- 文件被其他程序占用（如游戏正在运行锁住了存档）

生成过程有实时进度提示（扫描中 → 生成脚本 → 编译中）；完成后弹窗告知**文件在哪里、怎么使用**。

## 返回码 / 静默模式

`GameSaveHelper.exe` 自身支持 `-q`（静默，供脚本调用）：不弹窗，错误写 stderr，成功返回 0，失败返回 1，参数不合法返回 2。

## 目录结构

| 路径 | 说明 |
|---|---|
| `GameSaveHelper.exe` | 主程序（入口） |
| `config.json` | 游戏名 → 存档路径 配置（方式二用） |
| `nsis\makensis.exe` | NSIS 编译器（自动探测，也支持注册表/PATH） |
| `template\GameSaveHelper.nsi` | NSI 模板（`@@占位符@@` 由程序填充） |
| `src\GameSaveHelper.cpp` | C++ 源码；`build.bat` / `src\_cl.rsp`、`_link.rsp` 用于编译 |
| `out\` | 测试产物示例 |

## 重新编译主程序

```bat
:: 需要 MSVC（cl.exe）+ Windows SDK，见 build.bat 里的路径
build.bat
```
